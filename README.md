# Email Pilots

An Electron-based desktop application designed for reliable, rate-limited, and scheduled email outreach. Built with Vite, TypeScript, and Node.js.

## Documentation

The complete documentation for this project has been deepscanned and organized into the following markdown files:

- **[Features](docs/features.md)**: Detailed breakdown of the application's capabilities, including dynamic templating, spam checking, and anti-spam measures.
- **[Onboarding & Setup](docs/onboarding.md)**: Instructions for prerequisites, configuration (`.env`), and getting started.
- **[Procedures & Architecture](docs/procedures.md)**: Technical overview of the Electron architecture, mail processing flow, scheduling, and configuration management.
- **[Developer Steps](docs/steps.md)**: Standard commands for running, testing, and building the application.

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build the application:
   ```bash
   npm run build
   ```
