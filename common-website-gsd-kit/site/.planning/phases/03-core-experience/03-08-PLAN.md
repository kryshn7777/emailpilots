<objective>
Bake the Ch1 handwriting into the texture the paper shader will threshold, closing the Q2 slot Phase 2 reserved in `ingest.mjs`.

The mechanism is deliberately plain: authored strokes as ordered polylines, rasterised so each texel carries the *normalised arc-length position* of its nearest stroke point, written as an 8-bit PNG by ~40 lines over `node:zlib`. At runtime the fragment shader reveals every texel where `ramp ≤ progress`, with a small bleed so the 8-bit quantisation reads as a wet nib edge instead of a staircase. No text mesh, no runtime font work, one texture sample.

The reveal shader itself belongs to Ch1 (03-11) — this plan produces its input and proves the bake is deterministic.

Purpose: D3-05 lands as a real pipeline artifact; EXP-03's opening hook has its data.
Output: a tested bake script, an authored stroke set, and a committed ramp texture with recorded bytes.
</objective>

    - encodePng(width, height, rgbBytes) produces a buffer starting with the 8-byte PNG signature, an IHDR declaring the exact width/height with bit depth 8 and colour type 2, and ends with an IEND chunk

    - Texels beyond the brush radius of every stroke are 0 in both channels (background)
    - Region mask: strokes tagged `body`, `token`, `name` produce G values 0, 128, 255 respectively, and no texel carries an intermediate G value
    - The bake is deterministic: two runs over the same input produce byte-identical output

  <action>
    Create `pipeline/bake-ink.mjs` with a CLI (`node pipeline/bake-ink.mjs [--in <json>] [--out <png>] [--size WxH]`) and two exported functions.

    `encodePng(width, height, rgb)`: PNG signature, IHDR (bit depth 8, colour type 2 = truecolour, no interlace), a single deflated IDAT over filter-0 scanlines, IEND, with CRC32 per chunk implemented inline. Colour type 2 rather than 4 because the shader samples `.rg` from a plain colour texture and an alpha channel invites premultiply surprises; B is written 0 and documented as reserved.

    `bakeInk(strokes, opts)`: takes `[{ region: 'body'|'token'|'name', points: [[x,y], …] }]` in normalised 0..1 texture space. Walk every stroke accumulating global arc length; for each texel within `brushRadius` of any stroke segment, write `R = round(255 * globalArcLengthAtNearestPoint / totalArcLength)` and `G` = the region code. Nearest-point search may be a straightforward per-segment distance test — a one-time offline bake at 1024×512 has no performance requirement; add a `ponytail:` comment naming the O(texels × segments) ceiling and the upgrade path (spatial bucketing) if the stroke count ever grows past a few hundred.

    Default output size 1024×512 (research's figure — ~2 MB VRAM as an RGBA8 upload, negligible against the 128 MB texture line). Print a `[bake] ink-ramp: WxH, N strokes, M bytes` line and exit non-zero on any failure, matching the pipeline's fail-closed convention.
