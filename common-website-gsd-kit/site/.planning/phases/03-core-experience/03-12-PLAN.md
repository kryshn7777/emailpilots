    - pipeline/ingest.mjs — the conventions to mirror: `node:` stdlib imports, `spawnSync('toktx', args)` with a non-zero exit check, `[gate] <id> bytes: … — PASS/FAIL` reporting, `failClosed` semantics (remove output, exit 1), and the existing UASTC flag set used by `encodeTextures` including `--genmipmap --t2`
    - pipeline/bake-ink.mjs (03-08) — the sibling first-party bake's CLI shape and reporting style, for consistency

    - .planning/STACK-DECISION.md Amendment A3 toolchain note (this install's sharp resize path is broken; `toktx --resize` is the sanctioned resizer)
  </read_first>
  <action>
    Create `pipeline/bake-ui.mjs` with a CLI: `node pipeline/bake-ui.mjs <input.png> <output-id> [--sizes 2048,1024] [--max-bytes N]`.

    For each requested size it runs one `toktx` invocation: `--t2 --genmipmap --resize <n>x<n>` (or the aspect-preserving equivalent — the dashboard is not square, so resize on the long edge and record the actual dimensions rather than forcing a square), `--encode uastc --uastc_quality 2 --uastc_rdo_l 1 --zcmp 18 --assign_oetf srgb`. UASTC and not ETC1S is the whole point: this texture is small type, and ETC1S block artefacts on glyph edges are exactly the failure D3-06 was written to prevent. State that in the file's docblock so nobody "optimises" it to ETC1S later.

    Gate on bytes per output against `--max-bytes` (default 4,000,000 for the 2048 output). On a breach: print `[gate] ui/<id> bytes: N / ceiling M — FAIL`, remove the produced file, and exit 1 — same fail-closed contract as `ingest.mjs`, so an oversized texture can never sit in `public/assets/` waiting to be noticed.

    Write outputs to `public/assets/ui/<output-id>-<size>.ktx2` and print a `[bake] ui/<id>: WxH → N bytes` line per size.

    Keep it small. This is a toktx wrapper with a gate, not a pipeline — a `ponytail:` comment should say so and name the upgrade path (fold into `ingest.mjs` only if first-party assets ever need ledger parsing).
  </action>
  <acceptance_criteria>
    - `node pipeline/bake-ui.mjs` with no arguments exits non-zero with a usage message
    - `grep -c "uastc" pipeline/bake-ui.mjs` outputs ≥ 1 and `grep -ci "etc1s" pipeline/bake-ui.mjs` outputs 0
    - `grep -cE "^import .* from '(?!node:)" pipeline/bake-ui.mjs` outputs 0 (stdlib only; toktx is spawned, not imported)

    - `npm run check` exits 0
  </acceptance_criteria>
